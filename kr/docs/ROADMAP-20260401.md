# 로드맵: claude-howto 2026–2027

> 2026년 4월 – 2027년 3월 · 이중 계층 지식 베이스 | 전체 계획: `TASKS-20260401.md`

---

## 비전

claude-howto를 정적인 튜토리얼 저장소에서 **살아있는 이중 대상 지식 시스템**으로 변환합니다:

- **사람을 위한** — 점진적 난이도, 의사 결정 트리, 전문가가 북마크하는 명명된 패턴이 있는 대화형 시나리오 기반 학습
- **AI 에이전트를 위한** — 에이전트가 Claude Code 작업을 수행하기 전에 조회하는 구조화된 메타데이터 인덱스로, 이 저장소를 단순한 콘텐츠가 아닌 인프라로 만듭니다

어떤 경쟁자도 AI 에이전트를 주요 대상으로 삼지 않습니다. 이것이 경쟁 우위입니다.

## 마일스톤

### M1 — 인프라 구축 · 2026년 4월 말

**제공 내용:**
- `scripts/quickstart.sh` — 신규 사용자를 위한 원클릭 설정 (멱등)
- `QUICKSTART.md` — 첫 15분 시각 가이드
- 10개 모듈 전체에 난이도 배지 + "만들 내용" 미리보기
- `WHATS-NEW.md` + 모든 모듈에 버전 배지
- `.github/workflows/staleness-check.yml` — 모듈이 30일 이상 미검증 시 매주 월요일 이슈 생성
- 루트 `CLAUDE.md` — 모범 사례 예시로서의 프로젝트 자체 설정
- `scripts/build-agent-index.py` — 10개 모듈을 읽어 `agent-manifest.json` + `AGENT-INDEX.md` 출력
- **06-hooks** — 전체 심층 개선: 5개 완전한 hook 스크립트, 의사 결정 트리, 지금 시도하기, 패턴
- **08-checkpoints** — 전체 심층 개선: 311 → 800+ 라인, 3개 워크플로우 템플릿, 의사 결정 트리, 패턴

**왜 여기서 시작하는가:** 인프라는 모든 미래 단계에 혜택을 줍니다. Hooks와 checkpoints는 가장 약한 모듈이며 새 방문자를 잃을 가능성이 가장 높습니다.
