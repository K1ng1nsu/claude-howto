# 인시던트 대응

구조화된 인시던트 대응 워크플로우:

1. 인시던트 기록 생성
2. 심각도 및 영향 평가
3. 당직 팀에 알림
4. 진단 정보 수집
5. 대응 노력 조정
6. 해결 방법 문서화
7. 사후 분석 일정 계획
