# Claude How To - 디자인 시스템

## 시각적 아이덴티티

### 아이콘 디자인 콘셉트: 코드 브래킷이 있는 나침반

Claude How To 아이콘은 **`>` 코드 브래킷이 있는 나침반**을 사용하여 코드를 통한 안내된 탐색을 나타냅니다:

```
     N (초록색)
     ▲
     │
W ───>─── E     나침반 = 안내/방향
     │          > 브래킷 = 코드/터미널/CLI
     ▼
     S (검은색)
```

이는 다음을 만듭니다:
- **시각적 명확성**: 즉시 "코드 탐색 가이드"를 전달
- **상징적 의미**: 나침반 = 길 찾기; `>` = 코드/터미널
- **확장성**: 16px에서 512px까지 모든 크기에서 작동
- **브랜드 정합성**: 미니멀 팔레트로 개발자 도구 미학과 일치

---

## 색상 시스템

### 팔레트

| 색상 | Hex | RGB | 사용처 |
|------|-----|-----|--------|
| 검은색 (기본) | `#000000` | 0, 0, 0 | 메인 선, 텍스트, 남쪽 바늘 |
| 흰색 (배경) | `#FFFFFF` | 255, 255, 255 | 밝은 배경 |
| 회색 (보조) | `#6B7280` | 107, 114, 128 | 작은 눈금, 보조 텍스트 |
| 밝은 초록색 (악센트) | `#22C55E` | 34, 197, 94 | 북쪽 바늘, 중앙 점, 악센트 선 |
| 거의 검은색 (다크 배경) | `#0A0A0A` | 10, 10, 10 | 다크 모드 배경 |

### 대비 비율 (WCAG)

- 검은색 on 흰색: **21:1** AAA
- 회색 on 흰색: **4.6:1** AA
- 초록색 on 흰색: **3.2:1** (장식용 전용, 텍스트용 아님)
- 흰색 on 어두움: **19.5:1** AAA

### 악센트 색상 규칙

**밝은 초록색(#22C55E)은 하이라이트에만 사용:**
- 나침반 북쪽 바늘
- 중앙 점
- 악센트 밑줄/테두리
- 배경색으로 사용 금지
- 본문 텍스트에 사용 금지

## 아이콘 세부사항

### 나침반 사양

나침반 마크는 다음 기하학적 요소로 구성됩니다:

```
요소                 | 선/채움      | 색상
---------------------|--------------|------------------
외부 링              | 3px 선       | 검은색 / 흰색 (다크 모드)
북쪽 눈금            | 2.5px 선     | 검은색 / 흰색 (다크 모드)
기타 기본 방위 눈금  | 2px 선       | 회색 / 흰색 50% (다크 모드)
중간 방위 눈금       | 1.5px 선     | 회색 / 흰색 40% (다크 모드)
북쪽 바늘            | 채워진 다각형 | #22C55E (항상 초록색)
남쪽 바늘            | 채워진 다각형 | 검은색 / 흰색 (다크 모드)
> 브래킷             | 3px 선       | 검은색 / 흰색 (다크 모드)
중앙 점              | 채워진 원     | #22C55E (항상 초록색)
```

### 크기 진행

```
16px  → 링 + 바늘 + 쉐브론만 (최소)
32px  → 기본 방위 눈금 추가
64px  → 중간 방위 눈금 추가
128px → 전체 디테일, 모든 요소 선명
256px → 최대 디테일, 굵은 선
```

### 로고 간격

```
┌─────────────────────────────────────┐
│                                     │
│        최소 여백                     │
│         (로고 높이 / 2)              │
│                                     │
│    [나침반]  Claude                  │

│                                     │
└─────────────────────────────────────┘
```

### 아이콘 중심점

모든 아이콘은 캔버스의 중간점을 중심으로 합니다:
- 256px 캔버스의 경우 128×128
- 128px 캔버스의 경우 64×64
- 다른 UI 요소와의 정렬 유지

## 접근성

### 색상 대비
- 모든 텍스트가 WCAG AA (최소 4.5:1) 충족
- 초록색 악센트는 장식용이며 정보 전달용 아님
- 적색-녹색 색상 의존성 없음

### 확장성
- 벡터 형식으로 모든 크기에서 선명도 보장
- 기하학적 형태가 16px에서도 인식 가능
- 사용 가능한 크기에 따른 점진적 디테일

## 파일 형식 세부사항

### SVG 구조

모든 SVG 파일은 플랫 디자인입니다:
- 그라데이션 없음 (단색만)
- 필터 효과 없음 (블러, 글로우, 섀도우 없음)
- 깔끔한 선 및 채움 기하
- 반응형 크기 조정을 위한 viewBox
- 읽기 쉽고 주석이 있는 코드

### 브라우저 간 호환성

- Chrome/Edge: 완전 지원

## 커스터마이징

### 악센트 색상 변경

다른 악센트로 변형을 만들려면:

1. `#22C55E`의 모든 인스턴스를 원하는 악센트 색상으로 교체
2. 장식 요소의 대비 비율이 3:1 이상 유지되는지 확인
3. 검은색/흰색/회색 구조는 변경하지 않고 유지

### 크기 조정

```css
svg {
  width: 256px;
  height: 256px;
}
```

SVG는 viewBox를 통해 자동으로 크기 조정 — 변환 불필요.
