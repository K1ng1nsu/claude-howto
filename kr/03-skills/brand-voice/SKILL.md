# 브랜드 보이스 스킬

## 개요
이 스킬은 모든 커뮤니케이션이 일관된 브랜드 보이스, 톤, 메시징을 유지하도록 합니다.

## 브랜드 아이덴티티

### 미션
AI로 개발 워크플로우를 자동화하는 팀 지원

### 가치
- **단순함**: 복잡한 것을 단순하게
- **신뢰성**: 견고한 실행
- **역량 강화**: 인간의 창의성 실현

### 말투
- **친근하지만 프로페셔널** - 편안하지만 캐주얼하지 않음
- **명확하고 간결** - 전문 용어 피하고, 기술적 개념을 간단히 설명
- **자신감** - 우리가 무엇을 하는지 알고 있음
- **공감** - 사용자 니즈와 어려움 이해

## 작성 가이드라인

### 권장 사항 ✅
- 독자를 지칭할 때 "당신" 사용
- 능동태 사용: "Claude가 보고서를 생성합니다" (X) "보고서는 Claude에 의해 생성됩니다" (O)
- 가치 제안으로 시작
- 구체적인 예제 사용
- 문장을 20단어 미만으로 유지
- 명확성을 위해 목록 사용
- 행동 촉구 포함

### 금지 사항 ❌
- 기업 전문 용어 사용 금지
- 과도하게 친절하거나 지나치게 단순화하지 않기
- "저희는 믿습니다" 또는 "저희는 생각합니다" 사용 금지
- 강조 외에는 모두 대문자 사용 금지
- 텍스트 벽 생성 금지
- 기술 지식 가정 금지

## 어휘

### ✅ 선호 용어
- Claude ("the Claude AI" 아님)
- 코드 생성 ("자동 코딩" 아님)
- 에이전트 ("봇" 아님)
- 간소화 ("혁명" 아님)
- 통합 ("시너지" 아님)

### ❌ 피해야 할 용어
- "최첨단" (남용됨)
- "게임 체인저" (모호함)
- "활용" (기업어)
- "이용하다" ("사용" 사용)
- "패러다임 전환" (불명확)

## 예제

### ✅ 좋은 예제
"Claude가 코드 리뷰 프로세스를 자동화합니다. 각 PR을 수동으로 확인하는 대신 Claude가 보안, 성능, 품질을 검토하여 팀이 매주 몇 시간을 절약할 수 있습니다."

작동 이유: 명확한 가치, 구체적인 이점, 행동 지향적

### ❌ 나쁜 예제
"Claude는 최첨단 AI를 활용하여 종합적인 소프트웨어 개발 솔루션을 제공합니다."

작동하지 않는 이유: 모호함, 기업 전문 용어, 구체적인 가치 없음
