# 코드 리뷰 스킬

이 스킬은 다음에 초점을 맞춘 종합적인 코드 리뷰 기능을 제공합니다:

1. **보안 분석**
   - 인증/권한 부여 문제
   - 데이터 노출 위험
   - 인젝션 취약점
   - 암호화 약점
   - 민감 데이터 로깅

2. **성능 리뷰**
   - 알고리즘 효율성 (Big O 분석)
   - 메모리 최적화
   - 데이터베이스 쿼리 최적화
   - 캐싱 기회
   - 동시성 문제

3. **코드 품질**
   - SOLID 원칙
   - 디자인 패턴
   - 명명 규칙
   - 문서화
   - 테스트 커버리지

4. **유지보수성**
   - 코드 가독성
   - 함수 크기 (50줄 미만이어야 함)
   - 순환 복잡도
   - 의존성 관리
   - 타입 안전성

## 참조 파일

이 스킬은 리뷰를 수행할 때 읽어야 할 지원 파일을 포함합니다:

- **`templates/review-checklist.md`** — 보안, 성능, 품질, 테스트를 다루는 구조화된 체크리스트. 이 파일을 읽고 리뷰 중에 어떤 카테고리도 놓치지 않도록 가이드로 사용하세요.
- **`templates/finding-template.md`** — 심각도, 위치, 코드 예제, 영향 분석과 함께 개별 발견 사항을 문서화하기 위한 표준 템플릿. 이 파일을 읽고 이슈를 보고할 때 그 형식을 사용하세요.
- **`scripts/analyze-metrics.py`** — 코드 메트릭(함수 수, 클래스 수, 평균 줄 길이, 복잡도 점수)을 계산하는 Python 스크립트. 리뷰 중인 파일에서 실행하여 정량적 데이터를 수집하세요.
- **`scripts/compare-complexity.py`** — 파일의 두 버전 간 순환 및 인지 복잡도를 비교하는 Python 스크립트. 리팩토링 변경사항을 검토할 때 이전 및 이후 버전으로 실행하세요.

## 리뷰 템플릿

리뷰되는 각 코드에 대해 다음을 제공합니다:

### 요약
- 전반적인 품질 평가 (1-5)
- 주요 발견 사항 수
- 권장 우선 순위 영역

### 중요 이슈 (있는 경우)
- **이슈**: 명확한 설명
- **위치**: 파일 및 줄 번호
- **영향**: 이것이 중요한 이유
- **심각도**: Critical/High/Medium
- **수정**: 코드 예제

### 카테고리별 발견 사항

#### 보안 (이슈가 있는 경우)
보안 취약점을 예제와 함께 나열

#### 성능 (이슈가 있는 경우)
복잡도 분석과 함께 성능 문제 나열

#### 품질 (이슈가 있는 경우)
리팩토링 제안과 함께 코드 품질 이슈 나열

#### 유지보수성 (이슈가 있는 경우)
개선 사항과 함께 유지보수성 문제 나열
